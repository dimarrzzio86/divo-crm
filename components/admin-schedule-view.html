📅 Рабочие дни недели
Кликните по дню, чтобы переключить рабочий/выходной. По умолчанию воскресенье — выходной.
🗓️ Календарь особых дней
Кликните по дате, чтобы настроить особый режим: полный выходной или сокращённый день с особыми часами.
—
🟢 Обычный день — работает по расписанию
🟡 Выходной по расписанию — вс/пн (или другой день выше)
🔴 Полный выходной — студия закрыта (клик по дате)
🕐 Сокращённый день — особые часы (клик по дате)
🎉 Особые дни
Дни с нестандартным режимом: полные выходные или сокращённые. Кликните по дате в календаре выше.
